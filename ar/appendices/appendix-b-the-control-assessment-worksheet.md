# الملحق ب — ورقة عمل تقييم التحكّم

لكلّ قدرة حرجة من قدرات OpenStack، سجّل الأدلّة عن كلّ سؤال. فإذا كان الجواب «نظنّ ذلك»، فمستوى التحكّم لم يثبت بعد.

| السؤال | الأدلّة |
| ------------------------ | ---------------- |
| ما قدرة الأعمال التي تعتمد عليها؟ | |
| ما خدمات OpenStack المشاركة فيها؟ | |
| ما التبعيات الخارجية المشاركة فيها؟ | |
| من يملك القدرة؟ | |
| من يشغّلها؟ | |
| من يستطيع تشخيصها؟ | |
| من يستطيع استعادتها؟ | |
| هل الاستعادة مثبتة عمليًا؟ متى، وعلى يد من؟ | |
| ما الإشارات التي تدلّ على التدهور؟ | |
| ما التغييرات التي تؤثّر فيها عادةً؟ | |
| ما التخصيصات التي تؤثّر فيها؟ | |
| ما الانحراف القائم عن المنبع (upstream)؟ | |
| ما الاعتماد القائم على خبير وحيد؟ | |
| ما مستوى التحكّم الحالي (من مجهول ← مستدام، المعايير في الفصل 5)؟ | |
| ما أهمّ فجوة في التحكّم؟ | |
| ما الذي ينبغي فعله الآن؟ | |
| ما الذي يمكنه الانتظار، وإلى متى؟ | |
